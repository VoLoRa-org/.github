## Welcome to VoLoRa
VoLoRa (Voice over Long Range) is an open source mesh framework that allows for semi-realtime half-duplex telecommunications over vast distances, that is completely off-grid and self-sustained and healing.

VoLoRa is based on 2.4GHz LoRa and FLRC radio links with a [Reticulum]([url](https://reticulum.network/)) mesh network.
